- **CHECK** Page Q9: Match the spanning-tree feature with the protocol type. (Not all options are used.)  
  DECIDED BY CLAUDE, the site's answer is wrong. The site's picture and text table pair MSTP with 'Fast converging enhancement of IEEE 802.1D', RSTP with 'Cisco implementation of IEEE 802.1D', PVST+ with 'Proprietary per VLAN implementation of IEEE 802.1w' and MST with 'IEEE standard that reduces the number of STP instances'. Three of those contradict Cisco's definitions and the site's own explanations elsewhere ('802.1w, or RSTP, provides faster convergence'; 'Rapid PVST+ provides a separate instance of 802.1w per VLAN'). Used: RSTP = fast converging enhancement of 802.1D, PVST+ = Cisco implementation of 802.1D, MSTP = IEEE standard that reduces the number of STP instances. 'Proprietary per VLAN implementation of IEEE 802.1w' is Rapid PVST+, which isn't an item, so that box stays empty; MST (Cisco's name for its MSTP implementation) is the leftover item. Worth the owner double-checking.
